【 手順 0 】共通アースの構築

全ての回路の基準となるマイナス極を構築せよ。
・ワイヤーを1本用意し、Arduinoの「GND」ピンから、
白い板の「左側の青い線の列（−の列）」の適当な穴へ繋ぐ。

【 手順 1 】タイマーモジュールの接続

ディスプレイ裏面の刻印を確認し、4本の線を接続せよ。
・「CLK」 ➔ Arduinoの「2」番ピン
・「DIO」 ➔ Arduinoの「3」番ピン
・「GND」 ➔ 白い板の「左側の青い線の列（−の列）」
・「5V」 ➔ Arduinoの「5V」ピン

【 手順 2 】警告スピーカーの設置

黒い円柱型のブザーを、白い板の右半分の空きスペースへ接続せよ。

１．ブザー本体を挿す
・「長い足」を白い板の「1f」へ
・「短い足」を白い板の「4f」へ
２．ワイヤーで中継する
・ワイヤー1：Arduinoの「12」番から ➔ 白い板の「1j」へ
・ワイヤー2：白い板の「4j」から ➔ 「左側の青い線の列（−の列）」へ

【 手順 3 】信号機（LED）の設置

4つのLEDと抵抗器を接続せよ。
※LEDの短い足はすべて「左側の青い線の列（−の列）」へ。

◆ 自動車用（青/緑）
・ワイヤー: 8番 ➔ 1a
・抵抗器: 1b ➔ 5b
・LED: 長い足 5a / 短い足 左側の青い列

◆ 自動車用（赤）
・ワイヤー: 9番 ➔ 8a
・抵抗器: 8b ➔ 12b
・LED: 長い足 12a / 短い足 左側の青い列

◆ 歩行者用（青/緑）
・ワイヤー: 10番 ➔ 15a
・抵抗器: 15b ➔ 19b
・LED: 長い足 19a / 短い足 左側の青い列

◆ 歩行者用（赤）
・ワイヤー: 11番 ➔ 22a
・抵抗器: 22b ➔ 26b
・LED: 長い足 26a / 短い足 左側の青い列

【 手順 4 】解除コードの設置

★重要★ 7番ピンのワイヤーを、「左側の青い線の列（−の列）」に繋いでください。
